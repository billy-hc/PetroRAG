# PetroRAG
## Retrieval-Augmented Gen-AI Interpretation of NPHI–RHOB Crossplots  
This notebook implements a literature-grounded interpretation pipeline for neutron–density crossplots using local LLMs and OCR-based reference ingestion.

## Data Source
Volve Dataset - Well Log 15_9-F-11A

### Setup
- Download Ollama, LLaVA:7b, qwen2.5:3b (refer to https://ollama.com/ for guide)
- Create folder named "content" in the same folder as your project
- Download your well log, in my case well_train.csv and test_gambar.pdf, and put inside /content folder
- Directory should be /content/well_train.csv and /content/test_gambar.pdf
- Setup virtual environment (windows):
     ```
     python -m venv .venv
     source .venv\Scripts\activate
     ```
- Install required packages
     ```
     pip install -r requirements.txt
     ```
### The system integrates:

- Numerical well-log data (e.g. NPHI, RHOB)
- Image-based information (figures, cross plots, resistivity sections)
- Authoritative petrophysical literature (e.g. Asquith & Krygowski)

All interpretations generated by the model are explicitly grounded in retrieved reference material, minimizing hallucination and improving scientific traceability.

This project is designed for academic research, particularly undergraduate or graduate theses in geophysics / petrophysics.

### Key Objectives

- Interpret petrophysical cross plots (e.g. NPHI–RHOB) using LLMs
- Prevent unsupported geological claims via reference grounding
- Integrate multimodal data (numeric, text, image) in a controlled way
- Enable traceable, reproducible AI-assisted interpretation

## Models Used
#### Language Models
Qwen 2.5 (via Ollama) - grounded reasoning & interpretation

#### Vision–Language Model
LLaVA 7B (via Ollama) - visual description of figures and plots

#### Embeddings
nomic-embed-text (local, Ollama-based)
